| ADR-001 | WebとAPIを分離し、業務操作はFastAPIへ | 画面とビジネスロジックの責務を明確にする。APIはJWT/所有権を検証 |

## 費用台帳の削除・累積上限（2026-11-14、#18 / PR #59）

[バックエンドレビュー](https://github.com/sskohei/Alter/pull/59#issuecomment-6823419245)を受け、
削除前に残予約をreleaseする案を採用する。予約IDの追加による削除後の追跡は導入せず、
#56の匿名化契約を維持する。#30は呼出停止・課金結果照合後、同一トランザクションで
`budget.release_for_deletion`を呼んでから削除する。DBトリガーで未解放のままの削除を拒否し、
結果不明の予約を自動解放しない。#36が照合を担当する。
`max_session_usd`は同じAI/会話の全期間の残予約＋実費＋追加予約で判定する。
台帳集計の最適化は10人MVPの実測後に再検討する。
