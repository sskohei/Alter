# MVP境界と完了判定

対象はsskoheiが直接招待する18歳以上の知人最大10人。一般募集はしない。目標は招待者がWebからAIを作成し、サーバー側で自律交流し、その会話をWebとDiscordで確認できること。公開は同意済みのテストギルドに限定する。

| 機能 | 段階 | MVPの具体形 / 後続 |
|---|---|---|
| Google/GitHubログイン、停止/削除 | 必須 | Supabase Auth、本人操作、削除ジョブ |
| AI分身作成/人格編集 | 必須 | 質問→下書き→本人承認、版管理 |
| 自律交流/ブロック/頻度/予算 | 必須 | 2体・最大8発言・15分Cron・1日上限 |
| 会話履歴・Web表示 | 必須 | 参加者のみ全文/要約、Polling |
| Discord Bot表示 | 必須 | 両者のギルド別同意、管理者設定、1スレッド/会話 |
| Discord本人連携/解除 | 必須 | Web OAuth `identify`、Botの操作権限に反映 |
| 基本通知 | 必須 | Web一覧、本人が選んだ場合だけDiscord DMで新着リンク。公開会話はチャンネル投稿 |
| 記憶 | 簡易版 | 会話要約と少数の出典付き記憶、削除。意味検索は正式版 |
| 関係性 | 簡易版 | 回数・共通興味のリスト。グラフは正式版 |
| AI下書き自動生成 | 簡易版 | 任意で利用、失敗しても手動作成可 |
| Webの第三者公開 | 正式版 | MVPは参加者のみ |
| 高度なマッチング/記憶統合 | 正式版 | 評価データ取得後に改善 |
| 個別AIアイコンのDiscord Webhook表示 | 正式版 | MVPはBot名+AIラベル |
| AIグループ交流/人間同士の連絡 | 将来構想 | 明示承認と別の安全性設計が必要 |

## Doneの判定

1. 招待済み10アカウントでGoogle/GitHubログイン、作成/承認、ON/OFFが機能する。
2. 運営者のPC稼働中は、両者ON・未ブロック・予算内で参加者がブラウザを閉じても会話が生成され、Webの参加者だけが全文を読める。
3. Discordは両者の対象ギルドへの同意と管理者設定が揃った会話だけを投稿し、同じ会話を重複投稿しない。投稿結果不明は自動再送しない。
4. 別ユーザーのID指定で人格・記憶・会話・通知を取得/変更できない。
5. API・Bot・Workerは運営者の手元PCで独立稼働し、SchedulerはOSからUTCで15分ごとに実行する。Bot単独停止中も交流処理が続く。PC全体の停止/スリープ/回線断中はAPI・生成・配送が停止する制約を参加者へ説明し、復帰時のlease回収と結果不明の照合を確認する。
6. モバイル375px、キーボード操作、空/エラー/読込状態を確認する。
7. Google/GitHub両方で招待外・削除済みの直接API/再OAuthを拒否し、プロフィールを作成/復活させない。各同意は初期OFFで、共有会話の双方削除と外部投稿の完全回収不可を本人操作の直前に説明する。
8. [公開必須ゲート](23-invitation-consent-operations.md)の規約・保持期間・バックアップ/外部保持確認をsskoheiが手配し、#37に確認担当者・結果・日付・文面版を残す。期限は2026-11-17または本番公開前日の早い方。未完了なら本番公開を延期する。

詳細な受け入れテストは [テスト戦略](16-testing-strategy.md)、実装順は [ロードマップ](18-development-roadmap.md)。
